# 设计规范

> 来源：第 11 轮视觉规则（用户 2026-10-14 批准）、第 13 轮新视觉「橱窗招工启事」（用户 2026-10-16 批准，设计稿在 `docs/design/2026-10-window-notice/`）、第 19 轮「操作质感」（用户 2026-10-17 确认，偏 App 感，见文末）和 `src/components/ui/` 的实现。规则改了先改这里，再改组件。

## 原则

用户的要求是「保持简洁的同时操作易懂，同时能准确提供双方需要的信息」。做法是**减法加分层**：每个页面只突出一件事，次要信息收起，操作集中；同一功能只有一个入口、一个名字。

- 手机优先：先按 375 px 设计，再看桌面 1280 px。任何页面在 375 px 下不能横向滚动。
- 中文为主；职位名、职位描述按产品说明附英文。
- 不出现签证或移民建议，签证字段只陈述事实。
- **只在一处用装饰**：首页的「橱窗告示」（几张像贴在橱窗上的招工启事，桌面上略微倾斜叠放）。其余页面不用阴影、渐变、点状底纹和水印，分组只靠细线和间距。

| 变量 | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--background` | #f7f7f5 | 页面底色 | |
| `--surface` | #ffffff | 内容区 | |
| `--foreground` | #1c1c1a | 正文 | |
| `--muted` | #6b6b66 | 次要文字 | 白底 5.36，底色上 4.99 |
| `--border` | #e4e4df | 分隔线、边框 | |
| `--brand` / `--brand-soft` | #0f766e / #e6f4f2 | 品牌、主按钮、签证标签 | 白字在品牌色上 5.47；品牌色在浅底上 4.84 |
| `--ok` / `--ok-soft` | #147638 / #e8f5ec | 福利标签、已完成 | 5.08 |
| `--danger` / `--danger-soft` | #b91c1c / #fdecec | 急招、错误、危险操作、未读数 | 5.66 |

## 层级

三层：页面底色 → 内容区（白底，`Section`）→ 内容区里的分组（`Group`）。分组之间用间距和细线，**不在卡片里套卡片**。

## 字体

| 用在 | 字体 | 写法 |
| --- | --- | --- |
| 中文和大部分文字 | 系统字体（苹方、微软雅黑等） | 默认 |
| 英文：职位英文名、英文地名 | Archivo（`next/font/google`，只取拉丁字符，带 `wdth` 轴） | `font-latin`，并给元素加 `lang="en"` |
| 重要数字：时薪 | Archivo 窄体（`font-stretch` 68%）、粗 800 | `font-figure`，字号用 `text-[…]`，通常直接用 `Pay` |

中文永远走系统字体：Archivo 只有拉丁字符，同一行里的中文自动落到系统字体。

## 字号

文字只用五档（数字的 `font-figure` 除外），类名在 `globals.css` 的 `@theme` 里定义：

| 类 | 大小 | 用在 |
| --- | --- | --- |
| `text-meta` | 12 px | 时间、辅助说明（灰色），标签 |
| `text-body` | 14 px | 大部分正文、表单 |
| `text-subtitle` | 16 px | 分组标题、卡片标题、列表行 |
| `text-title` | 20 px | 页面标题、卡片上的薪资 |
| `text-display` | 28 px | 职位详情的薪资 |

## 时薪（`Pay`）

时薪是每个职位上最醒目的字，全站只用 `<Pay pay={job.pay} country={job.country} />` 显示：大号窄体数字（`font-figure`，品牌色），后面跟小号灰色「/小时」。

| `size` | 数字大小 | 用在 |
| --- | --- | --- |
| `card`（默认） | 30 px | 职位清单、卡片 |
| `detail` | 40 px | 职位详情 |
| `notice` | 46 px | 首页橱窗告示 |

拆分文字的纯函数是 `payParts()`（`src/components/ui/pay-parts.ts`）。

## 间距

| 类 | 值 | 用在 |
| --- | --- | --- |
| `space-y-section` | 12 px | 页面里内容区之间 |
| `py-group` / `pt-group` | 16 px | 内容区里的分组 |

页面左右留 16 px（`main` 的 `px-4`）。`Section` 在手机上贴边（向外伸出这 16 px，上下各一条线），640 px 起变成圆角面板。

## 圆角和阴影

> 第 19 轮起，改版过的页面按文末「第 19 轮：操作质感」的圆角和阴影做（卡片 16 px 加柔和阴影，控件 12 px）。下面是还没改的页面现在的样子。

- **圆角只有两档：** 标签 3 px（`rounded-sm`），其余（按钮、输入框、面板、菜单）6 px（`rounded-md`）。头像、未读数这类圆形元素用 `rounded-full`。
- **不用阴影，也不用渐变。** 层次靠底色、细线和间距。
- 旧页面里的 `rounded-lg`、`rounded-xl`、`rounded-2xl` 在 `globals.css` 里也映射到 6 px，`shadow-*` 映射为无阴影，所以第 13 轮各页面改完之前外观已经一致。新代码直接写 `rounded-sm`、`rounded-md`，不写 `shadow-*`。

## 按钮

`Button`（按钮）、`ButtonLink`（看起来像按钮的链接）、`buttonClass()`（给不能用组件的地方），高度 44 px（触摸目标），圆角 12 px（`rounded-control`，第 19 轮起是默认，不用再补；`pill` 是全圆），无阴影。输入框用 `inputClass()`：12 px 圆角、高 44 px。

| 级别 | 样式 | 规则 |
| --- | --- | --- |
| `primary` | 实心品牌色 | 一屏最多一个 |
| `secondary` | 描边 | |
| `danger` | 实心红色 | 确认删除、封禁、驳回、下架这一步的按钮 |
| `danger-secondary` | 红色描边 | 通往这类操作的按钮（比如「删除账号」打开确认） |
| `link` | 文字链接 | |

其余动作收进 `MoreMenu`（「更多」）。危险操作（结束招聘、举报）在菜单里显示为红色。`MoreMenu` 按 WAI-ARIA 菜单按钮模式实现：Enter、空格或 ↓ 打开到第一项，↑ 打开到最后一项；方向键、Home、End 移动；Esc 关闭并回到按钮；Tab 关闭。

## 标签

`<Tag>`：白底、细边框的小标签，圆角 3 px。颜色只有三种，含义固定；不传 `kind` 时按文字自动选（`tagKindFor`）：

| kind | 边框和文字 | 例子 |
| --- | --- | --- |
| `urgent` | danger，加粗 | 急招 |
| `perk` | brand | 包餐、包住 |
| `visa` | brand | 接受学签、持 AEWV 工签者 |
| `neutral` | 灰 | 审核中、其他状态 |

职位卡最多 3 个标签。

## 企业验证标识

`VerificationBadge`，三级一眼能分开：

| 级别 | 样式 | 解释（`VERIFICATION_EXPLANATIONS`） |
| --- | --- | --- |
| 认证雇主 | 实心品牌色 + 勾 | 已核对新西兰企业登记，并且是移民局的认证雇主（Accredited Employer）。 |
| 已验证企业 | 浅底品牌色 + 勾 | 已核对新西兰企业登记（NZBN），不是移民局的认证雇主。 |

## 导航

手机（< 768 px）用底部导航 `BottomNav`，按身份：

| 身份 | 项目 |
| --- | --- |
| 未登录 | 职位 · 聊天（先登录）· 我的（先登录） |
| 求职者 | 职位 · 聊天 · 我的 |
| 雇主 | 职位管理 · 发布（中间突出）· 聊天 · 我的 |

- 聊天显示未读数，最多「99+」，数目也写在 `title` 里；当前项 `aria-current="page"`，品牌色加粗，名字下面一条 3 px 的短线。
- 登录、发帖、编辑职位、`/admin` 这些专注流程隐藏底部导航。

## 职位列表

> 第 19 轮样板（#141）里职位列表的卡片换成了 `JobCard look="app"`，规则见文末；首页和雇主主页还是下面这种。

**每个职位一块**（`JobCard`）：白底，1 px `--border` 边框，6 px 圆角，块与块之间 12 px，空隙露出页面底色；块内边距手机 16 px、桌面 20 px；鼠标移上去边框变成品牌色。不加阴影。职位列表、首页「精选工作」、雇主主页的在招岗位、收藏列表都这样排。

第 13 轮原来是细线清单（职位之间只有一条浅线）。用户 10-16 验收时反馈「几个帖子挤在一起，根本看不清楚分界线」（#63），所以改成分块。这是「分组只靠细线和间距」的例外：一个职位是一个可以点的整体，边框标出它的范围。

**筛选**按组收起：地区、行业、工作类型、最低时薪、签证、食宿各一行，默认收起；行上写组名和已选的条件（一项写名称，如「地区 · Albany」，几项写「已选 2」），点击展开。已选条件在列表上方显示成可以单独去掉的标签。桌面上展开的组在条件生效、列表刷新后保持展开。

## 列表行

`LinkList`：一行一个去处（标题、可选的一行灰字说明、可选的数字、右箭头），高度至少 56 px。用于「我的」和「待办」。

## 求职者的五项条件

雇主最先看的五项，在求职者主页预览、`/candidates/[id]`、推荐人才卡片上**同一顺序、同一名称**：可上班时间、地区、期望时薪、语言、经验。

## 表单

- 标签在输入框上方，`text-body` 加粗；输入框高 44 px。
- 多行文字框用 `htmlFor` 关联标签，不要包在 `<label>` 里（否则输入的文字会变成标签名称的一部分）。
- 资料类表单自动保存，不放「保存」按钮；状态写清楚：「已自动保存到本机」，保存失败时说明原因，不显示已保存。
- 必填和选填分开，选填默认收起并写明还有几项没填。

## 无障碍

浏览器测试里的 axe 检查（WCAG 2.1 AA）不能有任何违规；触摸目标至少 44 px；只用颜色表达的状态要同时有文字（如资料完成度里每项的「已填 / 待填」）。

## 第 19 轮：操作质感（偏 App 感）

用户 10-17：「现在总感觉看起来是很廉价的网页」，要求打磨操作质感，风格偏 App。分三步：第一步是这一节的基础（令牌和共用组件，#140）；第二步拿职位列表和职位页做样板给用户看；第三步各线把自己的页面改过来。**品牌色、「找工」字标和时薪大字不变。**

### 动效令牌

在 `globals.css` 的 `:root` 里：

| 变量 | 值 | 用在 |
| --- | --- | --- |
| `--duration-press` | 120 ms | 按下和松开 |
| `--duration-ui` | 200 ms | 下拉、提示、淡入 |
| `--duration-sheet` | 280 ms | 底部弹层滑上来 |
| `--ease-app` | `cubic-bezier(0.2, 0, 0, 1)` | 都用这条：出得快，落得软 |
| `--press-scale` | 0.97 | 按下时缩小到的比例 |

Tailwind 里写 `duration-(--duration-ui) ease-(--ease-app)`；动画用 `animate-sheet-up`、`animate-pop-in`、`animate-fade-in`、`animate-toast-in`、`animate-shimmer`。**系统打开「减少动态效果」时**，所有动画和过渡都关掉，按下只变暗不缩放（`globals.css` 末尾的媒体查询）。不加动画库。

### 按下有反应

- 能点的东西都要有反应：`pressable`（按下缩到 0.97，松手回弹；按钮、卡片、标签、底部导航）或 `pressable-row`（按下变暗；整行宽的列表行，整行缩放看着像坏了）。禁用的不动。
- 桌面上再加 hover（卡片阴影加深、按钮变浅、行变底色）。
- `Button`、`ButtonLink`、`buttonClass()` 已经自带 `pressable`。

### 圆角和阴影（改版页面）

| 类 | 值 | 用在 |
| --- | --- | --- |
| `rounded-card` + `shadow-card` | 16 px，柔和两层阴影 | 卡片：去掉 1 px 硬边框，靠阴影和白底分出层次 |
| `rounded-control` | 12 px | 按钮、输入框、Select、列表里的选项 |
| `shadow-pop` | 较深的阴影 | 浮在页面上的东西：底部弹层、下拉、轻提示 |

点按区域至少 44×44；一屏的主操作（底部操作栏）用 `Button size="lg"`，高 48 px。

### 共用组件（`src/components/ui/`）

| 组件 | 做什么 | 注意 |
| --- | --- | --- |
| `Button` | 按下、`loading`（转圈、`aria-busy`、不能重复点）、禁用；`danger`、`danger-secondary`；`pill` | 提交到服务器的按钮都传 `loading`，防止点两次。圆角默认 12 px，`className` 里不用再写 `rounded-control` |
| `inputClass()`、`fieldBorder()` | 输入框和多行输入框（`multiline`）：高 44 px、12 px 圆角、16 px 字（手机聚焦不放大）、聚焦时品牌色描边 | `tone: "warn"`（缺项、没识别到）或 `"danger"`（不合规）把边框变黄 / 红；`Select` 的 `tone` 也是这个 |
| `Section look="app"` | 白底卡片（`rounded-card shadow-card`），没有边框，手机上也是卡片，不贴边 | 改版页面用它；里面照旧放 `Group`、`LinkList`，不再套卡片 |
| `LinkList` | 一行一个入口（我的、待办） | 按下整行变暗，伸到 `Section` 的左右边 |
| `Card`、`CardLink`、`cardClass()`、`rowClass()` | 卡片；`interactive` 的整张可点 | `CardLink` 里不要再放链接和按钮 |
| `BottomSheet` | 手机从底部滑上来，768 px 起是居中面板 | 原生 `<dialog>`：焦点不出面板；点遮罩、下拉把手、Esc、「关闭」都能关；内容里 `data-autofocus` 的元素先拿到焦点 |
| `Select` | 代替原生 `<select>`：手机用底部弹层，桌面用下拉 | 值放在同名的隐藏输入框里，GET 表单照常提交（没有 `name` 就不放）；传 `value` 就是受控的，由 `onChange` 更新（整张表单会被替换的地方，比如 AI 整理后的发布表单）；表单自己画标签时传 `id`（给触发按钮，`<label htmlFor>` 指向它）和 `hideLabel`（标签只给读屏）；JavaScript 跑起来之前（或没有 JavaScript）是原生下拉框。键盘：↑↓ 移动、Home / End、Enter 或空格选、Esc / Tab 关、按字母跳到下一个（`select-keys.ts`）。e2e 用 `chooseOption()` |
| `Checkbox`、`Radio` | 原生控件换外观 | 整行都是标签，高 44 px；测试照样 `check()` |
| `Skeleton`、`SkeletonCard`、`SkeletonList`、`ListPageSkeleton`、`DetailPageSkeleton` | 骨架屏，轻微明暗起伏 | 不用 `role="status"`（页面有自己的状态消息），外层 `aria-busy` 加一行屏幕阅读器文字 |
| `toast()` 和 `Toaster` | 收藏、发送、保存后屏幕底部一句轻提示，3 秒后消失 | 同样的话再出现只留一条，最多同时 3 条；`Toaster` 在根布局里，只有 `aria-live`，不用 `role="status"` |

### 加载

- 求职者的主要页面有 `loading.tsx`（职位列表、职位页、实习、专业职位、外部职位页、收藏和进度、职位提醒）：点进去马上出现骨架屏，不闪白。各线铺开时给自己的路由补上。
- 页面里慢的区块继续用 `Suspense` 加骨架屏。

### 样板：职位列表和职位页（第二步，#141）

用户看过前后对比、点头之后，其他页面照这几条改。

- **字号和灰字（`type-app`）：** 加在页面最外层，只在这一页生效，用户点头后再放到全站。手机上正文 15 px、小字 13 px、小标题 17 px；1024 px 起正文 16 px，其余各大一档；灰字 `--muted` 加深到 `#55554f`（白底 7.5:1）。
- **职位卡（`JobCard look="app"`）：** 白底卡片（`rounded-card shadow-card`），没有边框，卡与卡之间 12 px。第一行职位名和时薪；下面一行浅色要点：地点 · 用工形式和工时 · 班次 · 联系方式怎么给，不写「地区 / 工时 / 联系」这些前缀（`job-card-parts.ts`）。再下面一行：一个状态（急招优先，其次认证雇主或已验证企业，未验证不显示），加最多两个浅底标签（`bg-brand-soft`，不描边）。最后一行：雇主，右边「收藏」「申请」。整张卡可点（职位名的链接盖满整张卡），按下整张卡缩一点，桌面上 hover 阴影加深。
