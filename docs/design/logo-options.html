找工 Zhaogong · Logo 方案

三个方案都用网站现在的品牌青绿（#0f766e）和「橱窗招工启事」的风格；每个方案下面依次是：主标志（浅底、深底），只有图形的方块版（手机和桌面图标 512 / 192、apple-touch-icon 180），浏览器小图标（按真实大小 32 和 16 px 显示）。都没有用银蕨、奇异鸟或国旗。

方案 A · 告示卡

一张略微倾斜、贴着胶带的招工启事，上面一个「工」字，直接接上首页「橱窗告示」的样子，用户在首页看到的和图标是同一样东西。小图标放不下卡片和胶带，只留青绿方块上的「工」。

方案 B · 橱窗

一扇橱窗，窗里立着一个「工」：「橱窗招工启事」浓缩成一个图形。线条横平竖直，缩到 16 px 还是一个窗框加一个「工」。（最早试过让窗棂直接连到窗框，但那样看起来像「日」或「目」，所以横笔和窗框之间留了空。）

方案 C · 放大镜

镜片里一个「工」字：「找工」就是找工作，意思最直白，第一次见的人也看得懂。缺点是放大镜是很常见的搜索符号，辨识度不如 A、B；小图标把镜框和手柄加粗，保证 16 px 还能认出来。
