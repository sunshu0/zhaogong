# 0009 导出数据和删除账号：删什么、留什么

- 状态：已采纳
- 日期：2026-10-16（#54，PRD R-30）

## 情况

用户在第 14 轮选了「导出我的数据和删除账号」。依据是新西兰《2020 年隐私法》的查阅原则（本人可以拿到机构保存的关于自己的信息）和更正原则，以及不再需要的个人信息不应继续保存。

一个人的数据分在两处：

- **服务器**（`src/db/schema.ts`）：账号、登录会话、验证码、两种身份的聊天记录和已读通知（`chat_records`）、看过哪些职位的联系方式（`contact_views`）、审核员身份（`moderators`）；雇主身份还有企业（`employers`）和它发布的职位（`jobs`）。
- **浏览器**：两种身份的个人主页资料、发出的举报、浏览记录、还没发到服务器的聊天改动，按身份存在 `localStorage` 的 `zhaogong:` 开头的键里。

有些记录不只关于这个人：举报和审核记录关系到被举报的职位和平台安全；联系方式的查看次数是雇主的职位数据；企业被封禁后，删掉账号不应该让这家企业重新干净地出现。

## 决定

**导出**：「我的 → 数据与账号」下载一个 JSON 文件（`zhaogong-my-data-日期.json`）。`server` 部分来自 `exportAccountData()`（`src/db/account-data.ts`）；`thisDevice` 部分是浏览器里这个账号所有身份的条目（`localDataFor()`，`src/components/account/my-data.ts`），按键名列出。别的账号在同一台设备上的条目不导出。会话只导出身份和时间，不导出会话编号（它是 cookie 的哈希，导出没有意义）。

**删除**：输入登录邮箱确认后，`deleteAccount()` 在一个事务里：

| 数据 | 处理 |
| --- | --- |
| 账号、所有设备的登录会话、验证码 | 删除 |
| 两种身份的聊天记录和已读通知（`chat_records`） | 删除 |
| 审核员身份 | 删除；**最后一位审核员不能删除账号**（和 #50 的规则一致），要先添加另一位 |
| 这个人添加的审核员的「由谁添加」 | 改成 `deleted-account`，页面显示「由已删除的账号添加」 |
| 看过联系方式的记录（`contact_views`） | 保留次数，邮箱改成 `deleted-account` |
| 雇主身份发布的职位 | 全部下架（`removed`），职位上的联系方式（电话、微信、邮箱）清空、改为不公开 |
| 企业本身（名称、地区、验证状态、封禁） | 保留，不再属于任何账号 |
| 举报、审核记录 | 原样保留：举报不记举报人，审核记录只有职位、企业和规则，都不含这个人的信息 |
| 共享聊天表（`conversations`，还没启用） | 删除这个人作为求职者的会话和其中的消息、交换 |
| 浏览器里这个账号所有身份的条目、会话副本 | 删除（`forgetLocalData()`），别的账号的条目不动 |

删除后立刻退出登录，跳到「账号已删除」的说明。同一个邮箱可以重新注册，得到一个全新的账号（没有企业）。

**保留的理由**：

- 企业留着，是因为举报、审核记录和封禁都指向它；删掉会让审核历史断掉，被封禁的企业也能借删除账号「洗白」。演示企业重新变成可以开通的状态，新建的企业没有入口可以再认领。
- 查看次数留着，是雇主的职位数据（#55）；去掉邮箱后它不再指向任何人。
- 对方保存的聊天记录不删：按 #10 的设计，每个身份保存自己的一份，对方那份属于对方。页面上明确告诉用户这一点。

**防止漏表**：`src/db/account-data.test.ts` 检查数据库里每个名字含 `email` 的列都在删除和导出的处理范围内。以后新加带邮箱的表（例如 #52 收藏、#53 订阅提醒），这条测试会失败，提醒把新表加进 `exportAccountData()` 和 `deleteAccount()`。浏览器这一侧按 `zhaogong:` 前缀和身份键自动找，新加的按身份存储的键不用改代码。

## 后果

- 「我的」列表多了一行「数据与账号」（`/account/data`）。
- 接口：`myServerData()`、`deleteMyAccount(邮箱)`（`src/app/account/actions.ts`），见 `docs/api.md`。
- 只能导出和删除当前设备上的浏览器数据；别的设备上的资料要在那台设备上导出或删除。资料以后存到服务器后，这一条就不再需要。
- #60（审核记录写明审核员）加上审核员邮箱后，删除账号时要把它也改成 `deleted-account`；上面的测试会提醒。
