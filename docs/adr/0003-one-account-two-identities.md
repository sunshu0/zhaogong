# 0003 一个账号两种身份，可切换

- 状态：已采纳
- 日期：2026-10-12（`f5c7d13` A17）；服务器核对身份 `d73083d`（2026-10-13）

## 情况

餐馆老板自己也可能在找工作，求职者也可能开店招人。如果求职者和雇主是两个账号，同一个邮箱要注册两次，聊天和资料也会混。

## 决定

- 每个账号都能找工作；可以为**一家**企业开通雇主身份（演示店或新建企业，一家企业只能绑一个账号）。
- 会话里记当前身份 `activeRole`，账号菜单和「我的」页面切换；切换后去工作台。
- 聊天、主页、通知、浏览记录按「邮箱 + 身份 + 企业」分开存，切换后互不可见。
- 浏览器里的身份只决定显示什么。写操作的 Server Function 用邮箱在服务器上查账号绑定的企业，不信任浏览器传来的企业编号；企业被停用或解绑时以服务器为准。
- 导航按身份变化（第 11 轮 C2）：求职者没有「发布招聘」，雇主有「职位管理」和「发布」。

## 后果

- 每个读写本机数据的地方都要带身份分区（`identity-scope.ts`），切换身份时页面内容整块重挂。
- 在雇主页面不自动切换身份（曾经和「切换为求职者」打架），而是给一个按钮让用户确认。

## 补充：团队（#87，2026-10-17）

「一家企业绑一个账号」改为「一个账号一家企业，一家企业可以有多个账号」：开店的人是管理员，其他人由管理员邀请加入。雇主身份的聊天记录改为按企业存一份，团队里的人看到同一批对话。见 ADR 0012。
