# 0035 聊天常用语和开场白：存在账号上，没改过的不存，服务器拒收联系方式

- 状态：已采纳（导师 local_aeecc927 10-24 15:4x 派活，说明 `zg-scratch/mentor-aeec/brief-B-07.md`；执行 B local_396907ff 起草）
- 日期：2026-10-24。Issue #372（C2 常用语）、#373（C1 开场白）。文字由用户 10-24 15:4x 审定（`zhaogong-board/plans/draft-c1-c2-phrases.md`）。

## 情况

老板和求职者在聊天里反复打同样的话（「还招吗」「什么时候面试」「已经招到人了」）。用户定了两件事：

- **常用语（C2）：** 输入框上方一排，点一条就发出；求职者、老板各一套；可以加、改、删、排序，最多 10 条，每条最多 60 个字，可以恢复默认。
- **开场白（C1）：** 求职者从 3 条模板选一条，或者自己写（最多 200 字）。在职位页点「立即沟通」开始一个还没有消息、也没写草稿的对话时，填进输入框，不自动发出。

两样都不许有电话、微信、邮箱：交换联系方式要走聊天里现有的同意流程（ADR 0002），一点就发的话不能绕过它。

## 决定

### 1. 存在 `accounts` 上，没改过的不存

- 迁移 0034 给 `accounts` 加三列：`seeker_phrases`、`employer_phrases`（JSON 数组）、`chat_opener`（JSON：`{"template":1..3}` 或 `{"text":"…"}`）。同一个账号的两种身份（ADR 0003）各存一列，互不影响。
- **null 就是默认。** 默认的文字在聊天字典里（`phrases.seekerDefaults`、`employerDefaults`、`openers`），跟着页面语言显示中文或英文。只有本人改过、按了保存，才存他写的文字，从此不再跟语言变。「恢复默认」把列清回 null。开场白 null 是模板 1。
- 读写在 `src/db/chat-phrases.ts`，解析和上限在 `src/lib/chat-phrases.ts`（浏览器和服务器共用，纯函数）。读不出来的值（JSON 坏了、超了上限）当作默认，不报错。
- 账号导出（`exportAccountData`）带上 `chatPhrases`；删账号时跟着账号行一起删。隐私说明第 2 节「账号」一句加上「你改过的聊天常用语和开场白（没改过的不存）」。

### 2. 服务器重新检查，不信浏览器

`saveMyChatPhrases`（`src/app/[lang]/messages/phrases-actions.ts`）：

- 谁的：只看会话 cookie，存到这个账号上。没登录回 null。
- 条数、字数：去掉首尾空白，空的那条直接丢掉，再查最多 10 条、每条最多 60 个字（按字符数，一个表情算一个）；开场白最多 200 字、不能是空的。
- 联系方式：每一条、自己写的开场白都过一遍 `readContact`（发布职位的解析器，企业主页 #195 存的时候用的也是它）。有一条带了，**整个保存都不写**，回第几条、找到了什么，页面提示删掉再存。
- 先全部检查完再写；常用语、开场白哪样没传就不动哪样。

### 3. 常用语：点一下就发

- 输入框上方一排按钮（手机上横着滑），旁边「管理」打开对话框：改文字、上移下移（按钮，键盘能用，不靠拖拽）、删除、添加一条、恢复默认；求职者在同一个对话框里选开场白。
- 点一条走和「发送」一样的 `send`，不动正在写的草稿。
- 一条会触发聊天规则提醒（收费、卖签证、民族偏好，`outgoingWarningParts`）的，不直接发，而是放进输入框，提醒照常出来，由本人决定。默认的几条都不会触发。
- 账号的常用语加载完之前这一排是空的（位置先留着，输入框不跳），免得点到默认的、发错话。服务器没回答时也一直空着，聊天照常能用。

### 4. 开场白：填进输入框，不发

- 「立即沟通」的按钮在求职者身份下先加载账号的开场白。点下去，对话还没有消息、这个对话的草稿也是空的，才把开场白写成这个标签页的草稿（`chat-drafts.ts` 的 `writeDraftIfEmpty`），再跳到聊天页；输入框里就是它，本人看过、可以改，再按发送。
- `{职位}`（英文模板里是 `{job}`）换成职位在当前语言下的名字：英文页面用 `titleEn`，没有就用中文名。自己写的开场白里也可以用 `{职位}`。
- 已经有消息或已经写了草稿的对话，不填。

## 后果

- 每个账号多存最多三段短 JSON；没改过的人什么都不多存。
- 老板第 5 条「这个职位已经招到人了」放进了默认（用户 15:4x 定）：老板可以礼貌回绝，求职者不用干等。
- 英文模板的占位写成 `{job}`，不是草稿里的 `{职位}`：英文页面不能露出中文（ADR 0023）。其余文字和草稿一字不差。
- 没做的：常用语按职位分组、团队共用一套常用语、开场白自动发出（用户定了不自动发）。
