# 0027 举报附证据：选站内聊天消息（存举报时的快照）和截图，只给审核员看，处理完 180 天后删

- 状态：已采纳（用户 10-20 10:4x 要的功能，导师 10:4x 先定数字和做法，写进「待用户」，可改；编号 A 10:4x 在 Progress 登记）
- 日期：2026-10-20

## 情况

1. **用户原话：** 「这个职位举报加入允许上传聊天记录截图，最好能允许顾客选中 app 内部的聊天记录打包一起举报，我们在后台能看到」。收押金、卖工签这类问题，证据多半在聊天里：雇主在职位上不会写，私下才说。
2. **现在的职位举报**（`reportJob`，`reports` 表）只有原因和补充说明，不登录也能举报，表里不记是谁举报的（ADR 0026 情况 1「举报的补充说明不带举报人」）。
3. **证据里全是个人信息：** 聊天消息有雇主一方（团队里具体哪个人）和求职者双方的话；截图里可能有电话、微信号、头像、定位。新西兰《2020 年隐私法》和《个人信息保护法》都按适用来做（ADR 0026）。

## 决定

### 1. 选站内聊天消息（第一个 PR）

- **只能选自己的：** 举报人要登录；只列出他（求职者账号）和**这个职位所属企业**的对话里的消息（`conversations.seeker_email` 是他、`employer_id` 是这个职位的企业，哪个职位的对话都算）。服务器按会话的账号再查一遍每条消息的编号，不信浏览器传来的内容。
- **最多 20 条**（`EVIDENCE_MESSAGES_MAX`）。选择列表只列最近 200 条。
- **存快照：** 新表 `report_evidence`（迁移 0028）每条一行：举报编号、举报人邮箱、消息编号、谁发的（求职者 / 企业，企业一方带团队成员的名字）、文字、发送时间。对方以后删号、对话没了，审核员看到的仍是举报那一刻的内容。
- **举报人邮箱只记在证据上**：没附证据的举报照旧不记是谁。记邮箱是为了删除账号时一起删、导出时给他自己（见第 4 节），不给审核员看，也不告诉雇主。
- 不登录照样能举报，只是不能附消息。

### 2. 截图（第二个 PR）

- 最多 3 张，只收 JPG / PNG / WebP，每张 ≤5 MB，按文件内容判断格式，不信扩展名和浏览器给的类型。
- 服务器去掉元数据（EXIF，含拍摄位置）后再存；存在 `report_evidence` 同一张表（`kind = "image"`，存储里的键、格式、大小）。
- **存储做成可换的接口：** 开发环境放本机 `data/uploads/`（`.gitignore` 里），生产环境用 Cloudflare R2（以公司名义开，`docs/cloudflare-deployment.md` 加一项）。图片不公开，只能通过审核后台带权限的地址看。
- 细节（去元数据和重新编码的做法、地址的权限）在第二个 PR 里补进本节。

### 3. 谁能看

- 只有审核员，在审核后台的举报详情里看（B 做）。每次打开都按 ADR 0026 记一条：聊天消息记 `chat`，截图也记 `chat`，编号是举报编号。
- 雇主看不到证据，也不知道是谁举报的（举报页照旧写「举报不会告诉雇主是谁发的」）。
- 举报人在自己的导出里能看到自己交的证据。

### 4. 保留和删除

- **处理完 180 天后删证据**（`EVIDENCE_KEEP_DAYS`）：举报不再是「待处理」、`handled_at` 早于 180 天前的，删掉它的证据行（截图连同存储里的文件），举报本身照旧保留。没有定时任务（ADR 0008）：每个新西兰日第一次有人提交举报时顺手删，跟 ADR 0026 一样。
- 为什么是 180 天：处理完以后还要留一段时间应付申诉、同一雇主再被举报时对照；法律没有给数字（IPP 9、《个人信息保护法》第十九条「必要的最短时间」）。把握：中等，导师可改。
- **删除账号**：举报人删号时，他交的证据（`reporter_email` 是他的）一起删，举报本身留着（不带他的任何信息）。被举报的雇主删号不动证据：那是举报人的证据，到期照样删。
- **导出**：`ServerAccountData.reportEvidence` 列出他交过的证据（举报编号、类型、消息的发送方、文字、时间；截图只列格式和大小）。

## 后果

- 审核员能看到收押金、卖工签这类只在私聊里出现的话，处理举报有依据。
- 聊天消息的快照是第二份副本，要跟着隐私页写清楚（B：隐私页、条款补「举报时提交的聊天记录和截图」一段：用途、谁能看、保留多久）。
- 以后要是允许雇主一方举报求职者并附消息，按同一张表做，`reporter_email` 换成那个账号。
- 聊天里的举报（`ChatReportDialog`）原来就会带上被举报的那条或最近 100 条，存在举报人自己的聊天记录里，这次不动。
