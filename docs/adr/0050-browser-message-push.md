# 0050：主动开启的网页聊天提醒

- 日期：2026-10-28；Issue #420，用户批准 C5 开发。隐私页拟议修改待用户确认，本分支未批准合并或发布。
- 使用现有 Next/OpenNext、D1、Web Crypto；不增加推送 SDK 或新的收费服务。

## 行为

「我的」中主动开启，系统权限只在点击按钮时询问。没有完整、有效且匹配的 VAPID 密钥对时明确暂未开放，不弹权限框、不假报成功。浏览器不支持时说明限制，iPhone/iPad提示从主屏幕打开。

订阅归一个精确的登录会话、账号和身份，不能用同一个 endpoint 覆盖其他账号或其他会话。登录会话最多10条，开启尝试每10秒一次（原子检查），关闭不限频。客户端再次开启前先安全删除当前会话下的旧订阅、取消浏览器订阅，重新申请；退出后的旧浏览器订阅同样可取消后重新申请。订阅不存在也可幂等关闭，不探测其他账号的存在。

迁移0041增加 `push_subscriptions` 和 `push_setups`。会话外键级联删除，账号删除也显式清理；导出订阅资料及尝试时间，不导出会话标识。会话过期停止发送、随既有会话清理删除，不承诺在过期瞬间物理删除。角色切换暂停旧身份的提醒；发送查询同时核对当前会话身份、到期时间、企业成员关系和非审核员资格。

## 发送与点击

只在共享聊天的新文字或简历消息实际插入后，用 Next `after` 安排发送；读消息、轮询、空消息、不成功插入和已应用 ticket 不触发。沿用现有 ticket 的幂等边界，不声称分布式 exactly-once。发送为最佳努力，失败不撤回聊天，也没有离线重试队列。

锁屏只显示中英文通用「有新消息」；不发送正文、姓名、联系方式或简历。协议使用 RFC8291 aes128gcm + RFC8292 VAPID，Web Crypto 实现；独立 Node ECDH/HKDF/AES-GCM 解密及 ES256 验签测试检查线上格式。只接受 Google/Mozilla/Apple/Microsoft 的明确 HTTPS 推送域名，拒绝自定义地址、凭证、端口、片段和重定向，防止用户提交 endpoint 形成 SSRF。

每次最多50个接收者，每批10个、单次请求5秒超时，20秒后不启动新批次，给 Workers 背景任务留下余量。404/410只删除仍匹配原会话和更新时间的订阅，避免旧响应删掉新订阅。日志只含 sent/expired/failed/skipped 汇总，不打印 endpoint、密钥或聊天标识。

`/api/push/worker` 用 JavaScript MIME、root scope和no-store响应，避开语言proxy；无fetch监听或私密页缓存。push handler强制通用文字，点击仅允许同源 `/api/push/open`。该路由重新鉴权及核对对话所有权；未登录带同源返回路径去登录、角色不符到「我的」提示切换，GET永不自动切换身份。

## 测试与上线界限

ZG_E2E测试构建在发送器入口直接返回failed，绝不接触真实浏览器推送服务，也不伪称已送达。这个既有开关在编译期固定，普通部署构建不能运行时开启它。浏览器测试替代Notification/PushManager，开启、刷新、取消、角色隔离和重新登录仍走真实Server Actions及数据库；另测真实worker注册路径。普通单测mock fetch检查协议。

本机受控测试不证明真实浏览器厂商送达、iOS主屏幕行为或Cloudflare生产background生命周期；这些须用户配置正式密钥并授权上线后另验。部署步骤、两组测试配置和风险见 `docs/web-push.md`。隐私页第2/5/6/9/10节的中英文diff是待用户同意的具体成果，未同意前不合并。
